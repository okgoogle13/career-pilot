# Claude Desktop Documentation

This directory contains prompts and documentation specifically for Claude Desktop to review and execute migration work.

## Files

### REVIEW_PROMPT.md
Comprehensive prompt for Claude Desktop to:
1. Review the IDE-Claude Desktop integration system
2. Audit Phase 1 components using custom skills
3. Verify design token completeness (including motion tokens)
4. Propose an optimized master plan for rapid batch migration of remaining 25 components

**Usage in Claude Desktop**:
```
@docs/claude-desktop/REVIEW_PROMPT.md
```

## Integration with Antigravity

This directory bridges the work between:
- **Antigravity (IDE)**: Handles simple component migrations, volume work
- **Claude Desktop**: Handles complex components, strategic planning, compliance review

See `.migration/README.md` for the automation workflow.
