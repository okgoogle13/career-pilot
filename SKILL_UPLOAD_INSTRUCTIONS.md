# Skill Upload Instructions

The bundled "wave" strategy has been replaced by an individual skill upload strategy.
Upload each of the following skills individually to Claude Desktop for maximum flexibility.

## ✅ Priority High (Migration & Creation)
- **`component-builder`**: Create new, M3 production-ready components.
- **`component-transformer`**: Coordinate migration of legacy components.
- **`design-compliance-dashboard`**: Track migration progress.
- **`token-orchestrator`**: Audit and map tokens.

## ✅ Priority Medium (Testing & Scaffolding)
- `jest-test-scaffolder`: Generate unit tests.
- `storybook-scaffolder`: Generate Storybook documentation.
- `react-page-scaffolder`: Scaffold entire page structures.
- `api-contract-validator`: Validate API contracts.

## ✅ Priority Low (Utilities)
- `task-delegator`: Coordinate parallel agent tasks.
- `project-health-checker`: Check system health.
- `webapp-testing`: E2E testing with Playwright.
