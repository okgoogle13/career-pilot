# Career Copilot - Project Context

## Overview
Career Copilot is a comprehensive career assistance platform featuring a "Northcote Curio" design system (modeled after a Victorian naturalist/anatomist aesthetic).

## Tech Stack
- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Python, Genkit
- **Design System**: "Northcote Curio" (Material 3 Expressive base)
  - **Themes**: Gallery (Light/Warm) & Laboratory (Dark/Cool)
  - **Typography**: Federated type stack (Proclamation, Bloom, Field Note, Annotation)

## Configuration
- **Skills**: Located in `.claude/skills/`
  - `ui-engineering`: Components, Design System
  - `backend-engineering`: API, Models
  - `quality-assurance`: Testing, Audits
  - `operations`: Deployment
  - `agentic-core`: Meta-skills

## Key Commands
- **Dev**: `npm run dev` (Frontend)
- **Test**: `npm test` / `pytest`
- **Lint**: `npm run lint`

## Rules
- **Anti-Slop**: Use specific design tokens; avoid generic Tailwind colors where possible.
- **Aesthetics**: Prioritize "Moonlight on Velvet" and "Sunlight on Parchment" visual tonality.
